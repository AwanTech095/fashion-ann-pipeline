# Fashion MNIST ANN Pipeline

MLOps Assignment 2 | 23L-2554: End-to-end ML versioning with Git, DVC, and Google Drive.

This project uses a fully connected TensorFlow ANN to classify Fashion-MNIST images into ten clothing categories.

The pipeline prepares raw data, preprocesses it, trains the model, and evaluates its performance.

Target: at least 85% test accuracy.
